# Security Policy

## Supported Versions

WikiMaps is under active development (V1). Only the latest `main` branch receives
security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue for a security vulnerability.

Prefer one of these private channels:

1. **GitHub Security Advisories** — "Security" tab → "Report a vulnerability"
   (recommended).
2. **Email**: lukianos76@gmail.com

Please include, if possible:

- a description of the vulnerability and its impact;
- reproduction steps or a proof-of-concept;
- the affected version / commit.

## Response Times

- Acknowledgement: within **72 hours**.
- Initial assessment and remediation plan: within **7 business days**.

We will keep you informed of progress until resolution, and credit your report
(unless you prefer otherwise) once a fix is released.

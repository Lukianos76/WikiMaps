# Politique de sécurité

## Versions supportées

WikiMaps est en développement actif (V1). Seule la dernière version de la branche
`main` reçoit des correctifs de sécurité.

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir d'issue publique pour une faille de sécurité.

Privilégiez l'un de ces canaux privés :

1. **GitHub Security Advisories** — onglet « Security » → « Report a vulnerability »
   (recommandé).
2. **E-mail** : lukianos76@gmail.com

Merci d'inclure, si possible :

- une description de la vulnérabilité et de son impact ;
- les étapes de reproduction ou un proof-of-concept ;
- la version / le commit concerné.

## Délais

- Accusé de réception : sous **72 heures**.
- Évaluation initiale et plan de correction : sous **7 jours ouvrables**.

Nous vous tiendrons informé de l'avancement jusqu'à la résolution, et créditerons
votre signalement (sauf demande contraire) une fois le correctif publié.
